# Tic Tac Toe Project

Welcome to the Tic Tac Toe Project! This project is a classic implementation of the Tic Tac Toe game, developed to provide an interactive experience while reinforcing fundamental programming concepts.

## Overview

Tic Tac Toe is a simple yet engaging game where two players take turns marking spaces in a 3×3 grid. The objective is to be the first to get three of your marks in a horizontal, vertical, or diagonal row. Despite its straightforward rules, the game offers opportunities to explore strategic thinking and game theory. :contentReference[oaicite:0]{index=0}

## Features

- **Two-Player Mode**: Engage in a head-to-head match with a friend.
- **Input Validation**: Ensures that players make valid moves within the game grid.
- **Win Detection**: Automatically checks for winning conditions after each move.
- **Draw Detection**: Identifies when the game ends in a tie.

## Learning Objectives

This project aims to achieve the following educational goals:

- **Object-Oriented Programming (OOP)**: Utilize classes and objects to model the game components, promoting code modularity and reusability.
- **Game Logic Development**: Implement core game functionalities such as move validation, win/draw detection, and turn management.
- **User Interaction**: Handle user inputs effectively and provide real-time feedback within the console environment.
- **Problem-Solving Skills**: Develop logical thinking by translating game rules into programmable logic.
- **Version Control Practices**: Use Git for version control, enabling collaborative development and project tracking.
